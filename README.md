# Chào cậu, tớ là Dươngg! 👋

> Thích vọc công nghệ, AI, tự làm web — đến từ Phú Thọ 🇻🇳

## 🧑‍💻 Về tớ

Tớ là một người đam mê công nghệ, thích tự mày mò và xây dựng những thứ "tầm the world" 🌍. Tớ nghĩ ý tưởng, rồi biến chúng thành sản phẩm thật — không tutorial, không đồ chơi!

## 🛡️ Đang làm gì

Tập trung vào **an ninh mạng** và **hệ thống phân tán**:

| Project | Mô tả | Stack |
|---------|-------|-------|
| **GhostCircuit** | Hệ thống honeypot phân tán, bẫy và phân tích hacker realtime | Rust + Go + Python + NodeJS + React |
| **Threat Hunt** | Workbench săn lùng malware (parser PE/ELF/APK, YARA) | Rust + Go + Python + TypeScript |
| **WebDefend** | WAF ứng dụng web với AI phát hiện tấn công layer 7 | Go + Python + Next.js |
| **Security Log Fabric** | SIEM thu thập và phân tích log bảo mật | Rust + Go + Python |

## 🌱 Đang học

- An ninh mạng & an toàn thông tin
- Kỹ thuật mạng (DNS, IP, VPN...)
- Database: Supabase → Neon → Turso → MongoDB

## 🛠️ Tech tớ hay dùng

**Backend:** Python · Go · NodeJS
**Frontend:** React · TypeScript · TailwindCSS
**Khác:** Docker · Tailscale · n8n · GitHub Actions
